# Task 1.8.2.2.3: Develop Changelog Management System

## Scenario

Given a HACS integration repository with core version consistency validation
When I want to enhance the version management process
Then I should have access to advanced features for changelog management

## Instructions for Coding LLM

Develop a changelog management system:

- Create a tool to aggregate commit messages and pull requests since the last release
- Implement categorization of changes (e.g., features, fixes, documentation)
- Develop a function to generate a draft changelog for review before release

Please implement the changelog management system based on the above instructions. This system will be crucial for automatically generating comprehensive and well-organized changelogs, making it easier for developers to communicate changes to users and maintain a clear history of the project's evolution.
