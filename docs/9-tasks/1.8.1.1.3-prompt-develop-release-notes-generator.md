# Task 1.8.1.1.3: Develop Release Notes Generator

## Scenario

Given a HACS integration repository
When I create a new release
Then the release tag should match the manifest.json version
And release notes should document changes and fixes
And release should be properly tagged in Git
And HACS should detect the new version within 24 hours

## Instructions for Coding LLM

Develop a release notes generator:

- Create a tool to collect commit messages since the last release
- Categorize changes (e.g., features, bug fixes, documentation)
- Generate a formatted changelog for the release notes

Please implement a release notes generator based on the above instructions. Ensure that the implementation includes functionality to collect commit messages since the last release, categorize these changes into meaningful groups, and generate a well-formatted changelog for the release notes. This tool should automate the process of creating comprehensive and organized release notes, improving the quality and consistency of documentation for each release.
