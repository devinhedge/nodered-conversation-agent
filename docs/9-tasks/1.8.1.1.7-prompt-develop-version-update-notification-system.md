# Task 1.8.1.1.7: Develop Version Update Notification System

## Scenario

Given a HACS integration repository
When I create a new release
Then the release tag should match the manifest.json version
And release notes should document changes and fixes
And release should be properly tagged in Git
And HACS should detect the new version within 24 hours

## Instructions for Coding LLM

Develop a version update notification system:

- Create a notification mechanism within HACS
- Design user-friendly update prompts
- Provide options for users to view release notes before updating

Please implement a version update notification system based on the above instructions. Ensure that the implementation includes a notification mechanism within HACS, user-friendly update prompts, and options for users to view release notes before updating. This feature is crucial for keeping users informed about new releases and providing them with the necessary information to make informed decisions about updating their HACS integrations.
