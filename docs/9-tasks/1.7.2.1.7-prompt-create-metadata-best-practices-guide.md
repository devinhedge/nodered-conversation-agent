# Task 1.7.2.1.7: Create Metadata Best Practices Guide

## Scenario

Given the implementation of repository metadata validation for HACS integrations
When developers are creating or updating their HACS integration repositories
Then they should have access to a comprehensive guide on metadata best practices

## Instructions for Coding LLM

Create a metadata best practices guide:

- Document guidelines for writing effective repository descriptions
- Provide a curated list of recommended topics for HACS integrations
- Explain the importance of proper licensing and provide guidance on license selection

Please create a comprehensive metadata best practices guide based on the above scenario and instructions. The guide should be written in Markdown format and should provide clear, actionable advice for HACS integration developers. Include examples, explanations of why each practice is important, and how it contributes to the overall quality and discoverability of the integration.
